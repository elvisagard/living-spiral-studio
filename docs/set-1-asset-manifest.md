# Set 1 Asset Manifest

## Status

Phase 1 inventory is in progress. This manifest tracks only assets students may receive and the clean target exports used on the assessment pages.

## Shared Handling Rules

- Keep downloadable student sources raw and full resolution.
- Create lightweight WebP derivatives for webpage previews.
- Do not premask, crop, recolor, frame, label, or position raw student assets.
- Preserve original proportions.
- Store web assets under `frontend/public/assets/assessment-1x/`.
- Use simple lowercase filenames with hyphens.
- Record the source and license or creation method before release.
